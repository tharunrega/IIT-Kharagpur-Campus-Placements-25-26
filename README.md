# Placement Job Descriptions 2025–26

A clean, searchable job listing page for IIT Kharagpur campus placements.

## Features

- Search by company, role, or CTC
- Sort by any column (Company, Role, CTC, CV Open, Deadline)
- Filter by CTC range
- Pagination
- Direct links to full job descriptions

## Usage

Open `index.html` in any browser — no server needed.
